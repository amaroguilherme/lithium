Turn a mechanistic hypothesis into concrete literature searches.

This is what closes the loop. The exploratory track proposes candidates the standing
search strategies never mention — sigma-1, orexin, transdermal delivery, a device — and
without this step the proposal is a dead end: the system speculates about a target and
then never asks any database about it.

## What to search for

Look at the chain below. The steps marked `[ASSUMED]` are the ones with no citation —
they are precisely what a search could turn into `[supported]`, so they are where the
value is. For each, write a query that would find evidence bearing on **that step**.

Also search for the compound, class, or device itself in any population. Existing
literature on a candidate that nobody applied to bipolar I is exactly the transferable
evidence this project runs on.

Do **not** re-search the standing strategies — they already run daily. Search what is
specific to *this* hypothesis.

## Query construction

Write in the source's native syntax. For PubMed, MeSH terms and field tags work
(`"Receptors, sigma"[MeSH]`, `[pt]` for publication type). Prefer a precise query that
returns twenty relevant records over a broad one that returns two thousand.

The population may be anything — rodent, healthy volunteer, another disorder entirely.
Preclinical is welcome here. The grading system already discounts for indirectness; your
job is to find the evidence, not to pre-filter it.

`seeking` — name the chain step this query is meant to anchor, or say "the candidate
itself" when searching for the intervention in general.
